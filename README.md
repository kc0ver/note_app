## 📚 𝑵𝒐𝒕𝒆𝒔

一款轻量级、专注纯粹的本地笔记应用。

📝 记录所想 · 🎨 简约设计 · 🌙 深色主题



## ✨ 功能特点

· ✅ 轻量简洁 - 无多余功能，专注于笔记本身

· ✅ 深色主题 - 随系统主题切换

· ✅ 灵活排序 - 可按创建时间正序/倒序排列笔记

· ✅ 保存草稿 - 可保留未编辑完成的内容

· ✅ 本地存储 - 所有数据保存在本地，无需联网，保护隐私

## 📥 下载安装

进入 [release](https://github.com/kc0ver/note_app/releases) 页面下载最新安装包

## ⚙️ 系统要求

· Android 14 (SDK 34) 及以上
· 无需特殊权限


## 🚀 快速上手

1. 下载并安装 APK
2. 打开应用，点击右下角 ✏️ 按钮创建新笔记
3. 输入内容后点击右下角按钮保存
4. 在主页长按笔记可编辑或删除
5. 进入设置页面可切换正序/倒序显示
